## 一、im 插件族（`IM 插件`，直接改 `lib\index.js`）

### B1 · （IM 补丁-纯文本） —— AS_PLAIN（微信前剥 HTML）

**那是什么**：我猜——发给微信前把 HTML 卡片和 `**加粗**` 剥成纯文本，微信才不显示乱码。

**凭什么**：微信显示不了 HTML 卡片，原文进微信会带一堆标签。补丁脚本：`维护\（IM 补丁-纯文本）`。

**我可能错在哪**：1. 上游若后来支持了富文本，这层就多余；2. 剥法可能漏（嵌套 div、图片标签）。

**怎么推翻我**：微信里发一条带 `**` 和 `<div` 的消息，看是否还会露标签。

**后来**：2026-10-29 22:17 已验，见第八节。

**原片指针**：`维护\（IM 补丁-纯文本）`、`插件安装目录\@xmanrui\dsh-im\lib\index.js`

### B2 · （IM 补丁-去回声） / _v2.py —— AS_NOECHO2（网页的话别镜像回微信）

**那是什么**：我判断——三处按 `origin!=="dsh"` 加标记，让镜像不把网页说的话再发一遍微信，防回环。

**凭什么**：一次微信里出现网页原话的重复。补丁：`维护\（IM 补丁-去回声）`、`（IM 补丁-去回声 v2）`。

**我可能错在哪**：1. 来源只有两种值，第三种（同源回环）漏判；2. 打标记的 `origin` 上游一改就失效，升级即丢。

**怎么推翻我**：窗口说一句话，看微信里是否原话回显。有 → 补丁已经没了。

**后来**：2026-10-29 22:17 已验，见第八节。

**原片指针**：`维护\patch_im_noecho*.py`

### B3 · （IM 补丁-草稿） / （IM 补丁-RPC） / rpc_peek.py —— 草稿与 RPC 窥探

**那是什么**：我猜——草稿相关与 RPC 窥探，为了看/改 im 内部链路。

**凭什么**：想弄清微信镜像的收发路径。补丁：`维护\（IM 补丁-草稿）`、`（IM 补丁-RPC）`、`（IM 补丁-RPC 窥探）`。

**我可能错在哪**：窥探接口是我自己的调试需要，不是功能；上游一升级就全坏。

**怎么推翻我**：跑一次 RPC 窥探，能不能取到近消息；不能 → 失效。

**后来**：2026-10-29 22:17 已验，见第八节。
