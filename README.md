# AI 的底层逻辑是史山代码

> **权重那层改不动。能改的，是它上面盖的一层——顺序、规则、判据。**
> 这个仓库是我们的解构记录：本地 AI 的缺陷生在哪、哪一层能改、改了凭什么。

---

## 一句话

**AI 的底层逻辑是史山代码**——几十年历史堆出来的训练权重，本地 AI 的缺陷就生在它里面，**改不动**。
但那上面有一层**可改的**：顺序、规则、判据。饥框架里「接收矛盾 → 处理矛盾」那段，就是盖在这层史山上的可改层。

## 史山在哪

- **权重层（史山）**：模型参数，训练出来的。缺陷、偏见、优绩主义、短视——全焊在这里，本地改不了。
- **云端为什么能判断**：云端的调用链更长、数据更多，能在上面临时拼出联想。但底层那层史山一直在，谁的都在。
- **本地 AI 的短板**：不是不够聪明，是**没有那层能临时拼的联想**——它只有史山本层，没有云端的临时层。

## 可改层长什么样

| 层 | 可改？ | 例 |
|---|---|---|
| 顺序 | ✅ | 先取情境再下结论，还是先下结论 |
| 规则 | ✅ | 什么情况下这句判据失效 |
| 判据 | ✅ | 「多」的判据是什么、拿最可能错的例子跑一遍 |

**判据：能写进「凭什么改、可能错哪、怎么推翻我」的，才叫可改层。写不出的只是换了一个说法。**
